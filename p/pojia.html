破甲助手是什么

破甲中转站是一个 AI 接口服务：把 GPT、Claude、Gemini、Grok、DeepSeek 这些模型收进同一个地址， 你只要拿一串密钥、填一个 base_url，就能在任何支持 OpenAI 协议的客户端里调用。

多模型一个入口切模型只改 model 字段，不用分别申请一堆账号，也不用在平台之间来回切。
兼容 OpenAI 协议base_url 指过来即可，OpenAI SDK、NextChat、Cherry Studio、Cursor、沉浸式翻译全部直接可用。
流式输出SSE 逐字返回，聊天类应用体感与官方一致，不憋稿。
额度按量计费用多少扣多少，团队共用一份额度，不必给每人单独开号。
密钥集中管理一把密钥分发，随时单独吊销，用量明细后台可查。
多线路兜底上游抖动自动切换线路，重试放在中转层，客户端不用写容灾。

破甲助手支持哪些客户端

OpenAI 官方 SDKNextChatCherry Studio Cursor沉浸式翻译LobeChat Chatbox任何自定义 base_url 的客户端

三步接入

第一步：注册领密钥

打开站点注册，控制台生成 API Key。

第二步：换掉 base_url

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的密钥",
    base_url="https://ai.tt2066.top/v1"
)

第三步：照常调用

resp = client.chat.completions.create(
    model="claude-sonnet-4",
    messages=[{"role": "user", "content": "你好"}],
    stream=True
)
